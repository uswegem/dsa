Decisions worth your attention
  1. Yellow is an action color only. It never fills a large surface — a full-bleed yellow page would drown the logo and fail contrast for text.
  2. Warning amber (#A85F00) is pulled away from brand yellow on purpose, so status and action never blur.
  3. LOCKED runs are black with yellow type — the logo lockup in miniature, and the strongest badge in the set for the most final state.
  4. Type is Poppins throughout. Buttons and inputs carry a 6px radius; panels, table headers and badges stay square, so the softening reads as interactive affordance rather than decoration.
